# 研记模拟卷版（Safari 私人版）

这是一个与原「研记」**完全分开的**静态网页项目。它不需要后端服务器、数据库账号、移动应用商店上架，也不向开发者上传题库、试卷和个人作答记录。

## 已实现功能

- **V1.1 PDF 试卷导入与拆题：** 直接上传 PDF 到 Safari 本地原件库；文字型 PDF 按题号自动切分，扫描版可选择本地中文 OCR 或点击页图手动设切分线；逐题修改题干、题型、分值、勾选入库；可保存原卷截图片段以保留公式/图形，或仅存文本；支持自动生成同名模考试卷。OCR 需首次联网下载语言模型，中文数学 OCR 可能有误。PDF 原件单独保存，不包含在 JSON 完整备份中，备份时需单独保存 PDF。

- 题库：手工录入、编辑/删除试题；支持图片、LaTeX 数学公式、参考答案与解析；按科目、来源（真题/模拟卷等）、年份、章节/知识点、题型、难度、关键词筛选；收藏。
- 题目导入与导出：UTF-8 CSV、JSON 数组、完整本地 JSON 备份；以题干和来源为依据跳过重复题目；演示题可选择导入（原创，非网站真题）。
- 选题篮：自由选题、调整题序、清空、保存为套卷；智能抽题（按科目、来源、难度、章节及各题型数量筛选，可优先未做题或错题）。
- 试卷：命名、复制、删除、编辑题目顺序和分值，设定考试时长、A4/A3、主观题留白高度（毫米）及是否附答案。
- 模拟考试：限时答题、标记待检查题、自动保存、超时交卷、自动判单选与多选、主观题自主评分。
- 复盘：历史模考成绩、按题型/章节的得分统计、错题专项重新组卷及题库收藏。
- 打印：调用 Safari 打印/保存 PDF，支持 A4/A3 版式及可选的答案解析页。
- PWA：启用 GitHub Pages 后支持「添加到主屏幕」，本地资源由 Service Worker 缓存。

## 使用 GitHub Pages（单独新建仓库）

1. 登录 GitHub，点击 `New repository`，仓库名建议 `yanji-mock-exam`，选择是否公开。**不要在旧「研记」仓库操作**。
2. 解压 ZIP，上传其中的全部文件（`index.html`、`app.js`、`pdf-import.js`、`styles.css`、`manifest.webmanifest`、`sw.js`、`sample-questions.json`、`icon.svg`、3 张 PNG 图标、`README.md`），所有文件直接放在仓库根目录，提交到 `main`。
3. 在仓库 **Settings → Pages → Build and deployment**，选择 **Deploy from a branch**，分支 `main`，目录 `/(root)`，保存。
4. 等待 GitHub Pages 显示网站网址，常见格式为 `https://你的用户名.github.io/yanji-mock-exam/`，在 **Safari** 打开此网址。
5. Safari 分享菜单 → **添加到主屏幕**（可选）。建议固定通过一个入口使用。

**注意：** GitHub Pages 部署本身会让网站在网络上可访问；它与项目内的「发布试卷」或「社区分享」功能不同。公开仓库源代码可见，个人题库和答案默认只在你自己的 Safari 中存储，不会进入仓库。若想保持网站源码访问私有，请先核对 GitHub 当前账户和 Pages 对私有仓库的支持情况。

## 本地开发

只需一个支持静态文件的 HTTP 服务器，例如：

```bash
python3 -m http.server 8000
```

随后访问 `http://localhost:8000`。不能保证直接在 Safari 打开 `file://` 的 HTML 时 IndexedDB 和 PWA 能正常使用。

## 数据安全

- 当前项目采用 `IndexedDB` 保存数据，数据库名 `yanji-mock-standalone-v1`，不读写旧「研记」的数据库。
- 题目图片会在本地存储；Safari 存储空间受设备与系统回收策略影响，请在设置中**定期导出完整备份**到「文件」或 iCloud Drive。
- 不同域名、Safari 普通标签页、主屏幕独立 Web App、无痕浏览或不同 Safari 资料可能互不共享 IndexedDB。浏览器中看到空题库不代表原数据在其他入口已被删除。
- 更新源代码不会自动删除题库；但若你更换部署域名，会出现一个新的数据作用域，请先备份再导入。

本项目是原创独立工具，**没有抓取、复制或同步该站的受限题库、会员系统或账户数据**。`https://bbkaoyan.cn/account` 是该站登录后的账户入口，仅提供 URL 无法让开发者访问你已登录的私有页面，因此目前只可确认本项目列出的已实现功能，不能声称该站全部注册后功能都已经逐项复刻。

## V1.2：重复试卷提醒与拆题去重

- 上传 PDF 时先计算 SHA-256 原文件指纹。**完全相同的文件即使改名也会提示重复并阻止再次保存**，可选择打开之前的原件。
- 如果 PDF 被重新导出、修改了元数据，则比较相同页数的逐页标准化文本内容；无可靠文字层的扫描卷，还比较每页图像的墨迹特征。为避免误判，只在满足较严格条件时判为同一张试卷。
- 首次遇到旧版保存的 PDF 时会尝试为其建立指纹；无法读取的旧文件会被跳过而不会删除记录。
- 题目入库时，按规范化题干（忽略题号和多余空白，**保留数学符号、括号等有意义的内容**）进行跨试卷全库查重；同一套卷内再次出现的相同题目也只入库一次。
- 文字不一致或无文字层时进一步对比原卷题目截图。高度相似但不确定的题目会请用户确认，不自动删除；相同题目会复用已存在的题库 ID，并在新试卷中正常引用。
- 如果已存在题目 ID、数量和顺序相同的套卷，就不再创建第二套。

**注意：** 这是尽力降低重复的机制，并不保证语义改写、OCR 错字、不同截图裁剪下的同题都能自动识别。不同题目只是相似时也可能需要人工确认。本次更新不会自动删除历史题库里已有的重复记录，请先备份数据，再决定是否整理旧题。
